# AdobeAudition-RU

[![Adobe Audition 2026+](https://img.shields.io/badge/Adobe%20Audition-2026%2B-9999FF.svg)](#требования)
[![PowerShell](https://img.shields.io/badge/PowerShell-5.1%20%7C%207-5391FE.svg)](#требования)

**AdobeAudition-RU** — русский язык интерфейса для установленного Adobe Audition 2026 и новее. Это настоящий язык `ru_RU`, а не русский текст, подложенный вместо испанского или другого языка. Установка, переключение языка и полный возврат выполняются одним скриптом PowerShell.

## Быстрый старт

Откройте PowerShell и выполните:

```powershell
irm https://github.com/coinman-dev/AdobeAudition-RU/releases/latest/download/Install-AuditionRU.ps1 | iex
```

Или скачайте [`Install-AuditionRU.ps1`](https://github.com/coinman-dev/AdobeAudition-RU/releases/latest/download/Install-AuditionRU.ps1) из последнего релиза и запустите его: «Выполнить с помощью PowerShell». Скрипт сам запросит права администратора и откроет меню:

```text
  Adobe Audition 2026 26.5.0.82
  Язык интерфейса:    English (en_US)
  Русификатор:        не установлен
  Исправление DLL:    не применено (исходная DLL)

   * 1. Установить / обновить русский язык
     2. Переключить язык интерфейса
     3. Удалить русификатор (вернуть как было)
      0. Выход
```

Перед установкой и переключением языка закройте Adobe Audition.

Установка кладёт меню русификатора в папку Audition: `AdobeAudition-RU\AdobeAudition-RU.cmd` (обычно `C:\Program Files\Adobe\Adobe Audition 2026\AdobeAudition-RU\AdobeAudition-RU.cmd`). Запустите его двойным щелчком, чтобы переключить язык, обновить перевод или удалить русификатор. Скачивать скрипт заново не нужно.

Если антивирус заблокировал `powershell.exe`, см. раздел [Антивирус](#антивирус).

## Как это устроено

В Audition нет ни файла `.langpack`, ни пункта меню для выбора языка. Язык определяют три вещи:

| Что | Где | Что делает скрипт |
|---|---|---|
| Строки интерфейса (~15 000) | `dict\ru_RU\zdictionary_AUDT_ru_RU.dat` | собирает под установленную версию |
| Общие строки модулей Adobe (~7 700) | `dict\ru_RU\dva_ru_RU.dict` | собирает под установленную версию |
| Справка F1 | `HelpCfg\ru_RU\Audition_*.helpcfg` | создаёт из английского файла этой версии |
| Выбранный язык | `AMT\application.xml` → `installedLanguages` | меняет значение |
| Список разрешённых языков | `AuApplication.dll` | меняет 2 байта (см. ниже) |

**Зачем трогать DLL.** Функция `app::SetLocalePref` в `AuApplication.dll` проверяет язык по зашитому списку: de, en, es, fr, it, ja, ko, pt_BR, zh_CN. Любой другой язык, в том числе `ru_RU`, молча заменяется на `en_US`. Скрипт находит эту проверку по экспорту функции и характерной последовательности байтов (`jne` + `lea rdx, "en_US"`), а не по адресу. Затем он заменяет `lea` на короткий `jmp`, и программа принимает выбранный язык. Для любой версии, где такая последовательность найдена ровно один раз, меняются ровно 2 байта. Если последовательность не найдена, скрипт ничего не меняет и сообщает об этом.

**Любая версия 2026+.** Словари собираются по ключам английского словаря установленной версии. Строки, которых нет в переводе (новые функции), остаются английскими, и сырых ключей `$$$/...` в интерфейсе не будет. Скрипт показывает, какая доля строк переведена.

## Что меняется и как вернуть

Ничего не удаляется. Прежние файлы и настройки сохраняются в `<папка Audition>\AdobeAudition-RU\`:

- `backup\AuApplication.dll` — исходная DLL;
- `backup\dict\...`, `backup\HelpCfg\...` — файлы, которые лежали на месте русских (например, из установщика с русской подменой);
- `state.json` — исходный язык, список установленных файлов и их SHA256;
- `AdobeAudition-RU.cmd` и `Install-AuditionRU.ps1` — меню русификатора: копия скрипта, которым выполнялась установка. Копия настраивает Audition, в папке которого лежит.

Пункт меню **«Удалить русификатор»** (`-Action Restore`) возвращает исходную DLL, прежний язык и прежние файлы, а затем удаляет папку `AdobeAudition-RU` вместе с меню. Изменённые после установки файлы он не трогает.

После обновления Audition новая `AuApplication.dll` будет без исправления. Меню покажет это в строке «Исправление DLL»; запустите установку ещё раз.

## Загрузка и проверка файлов

Файлы берутся из [GitHub Releases](https://github.com/coinman-dev/AdobeAudition-RU/releases): у каждого релиза свой тег и `manifest.json` с размером и SHA256 каждого файла и архива.

1. Скрипт скачивает `manifest.json` последнего (или указанного через `-Release`) релиза.
2. Если в `%TEMP%\AdobeAudition-RU\<версия>` уже есть проверенные файлы этой версии, установка идёт сразу, без загрузки.
3. Иначе скачивается архив: через `curl` в файл `.part`, затем проверяются размер и SHA256 архива и каждого файла внутри.
4. Если GitHub недоступен, используется последний проверенный кэш.

Если скрипт лежит в клоне репозитория (рядом `manifest.json` и `ru_RU`), файлы берутся из клона и тоже проверяются по SHA256.

## Антивирус

Скрипт делает то, за чем следят поведенческие эвристики антивирусов: скачивает файлы из интернета, меняет файлы в Program Files (в том числе 2 байта в DLL) и перезапускает PowerShell с правами администратора. Поэтому антивирус может принять русификатор за вредоносную программу.

До версии 0.1.2-beta скрипт перезапускал себя командой `powershell.exe -EncodedCommand …`, и Avast блокировал её как угрозу `IDP.HELU.PSE91` («обнаружено в командной строке»). Теперь перезапуск — обычная команда `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <путь к скрипту> <параметры>`. При проверке с Avast такая команда срабатывания не вызывает.

Если антивирус всё же сработал:

- Откройте PowerShell от имени администратора (Win+X → «Терминал (администратор)» или «Windows PowerShell (администратор)») и выполните в нём команду из [быстрого старта](#быстрый-старт). Тогда скрипту не нужно перезапускаться.
- Не отключайте антивирус и не добавляйте `powershell.exe` в исключения.
- Сообщите о ложном срабатывании производителю антивируса и в [Issues](https://github.com/coinman-dev/AdobeAudition-RU/issues).

Код скрипта открыт, файлы перевода проверяются по SHA256, а пункт «Удалить русификатор» возвращает всё, что скрипт изменил.

## Параметры

| Параметр | Назначение |
|---|---|
| `-Action Menu` | меню (по умолчанию) |
| `-Action Install` | установить или обновить русский язык |
| `-Action Switch -Language en_US` | переключить язык: `ru_RU`, `en_US` или другой установленный |
| `-Action Restore` | удалить русификатор и вернуть всё как было |
| `-Action Status` | показать состояние (права администратора не нужны) |
| `-AuditionPath <папка>` | папка Audition, если их несколько или путь нестандартный (копия в папке Audition берёт свою) |
| `-Release v1.0.0` | конкретный релиз вместо последнего |
| `-Source <папка>` | взять файлы из локальной папки с `manifest.json` |
| `-LearnPanel` | установить также перевод обучающей панели (включает `PlayerDebugMode`, см. ниже) |
| `-Yes` | без вопросов |
| `-UILang ru\|en` | язык сообщений скрипта (по умолчанию — язык Windows) |
| `-NoPause` | не ждать клавишу перед выходом |

Примеры:

```powershell
.\Install-AuditionRU.ps1 -Action Install -Yes
.\Install-AuditionRU.ps1 -Action Switch -Language en_US
.\Install-AuditionRU.ps1 -Action Restore
```

Те же параметры принимает `AdobeAudition-RU.cmd` из папки Audition.

## Обучающая панель

Панель «Обучение Audition» — отдельное подписанное расширение Adobe CEP. Проверено на Audition 26.5: если добавить в неё файлы перевода, CEP отказывается её загружать с ошибкой «Недопустимая сигнатура». Поэтому перевод панели ставится только по запросу (`-LearnPanel` или вопрос при установке). Вместе с ним скрипт включает `HKCU\Software\Adobe\CSXS.<N>\PlayerDebugMode = 1`, после чего панель открывается на русском. В этом режиме CEP загружает изменённые и неподписанные панели всех программ Adobe этого пользователя. При удалении русификатора прежнее значение возвращается.

## Перевод

- Около 5 000 новых строк Audition 2026 переведены заново. Названия форматов, стандартов, брендов, кодов ошибок, клавиш и MIDI-контроллеров оставлены латиницей.
- Любительский перевод 2023 года полностью вычитан: исправлено около 3 750 строк. Строки из официального перевода Adobe (`dva_ru_RU`) сохранены.
- Названия меню, панелей и команд согласованы во всём интерфейсе, включая редактор сочетаний клавиш.

Ошибки перевода и неподдерживаемые версии: [Issues](https://github.com/coinman-dev/AdobeAudition-RU/issues).

## Требования

- Adobe Audition 2026 (26.0) или новее, Windows x64.
- Windows PowerShell 5.1 или PowerShell 7.
- Права администратора: папка Audition лежит в Program Files.

## Для разработчиков

```powershell
.\tests\Test-AuditionRU.ps1              # проверки; полный цикл — на копии Audition во временной папке
.\tools\New-Release.ps1 -Version 1.0.0   # manifest.json + out\release\v1.0.0\
gh release create v1.0.0 "out\release\v1.0.0\*" --title v1.0.0 --notes-file CHANGELOG.md
```

Файлы словарей хранятся в Git как двоичные (`.gitattributes`), чтобы их SHA256 совпадали с `manifest.json`.

`Install-AuditionRU.ps1` в репозитории — UTF-8 с BOM. В релиз `New-Release.ps1` кладёт его копию только из ASCII-символов: русский текст в строках записан кодами символов, русских комментариев нет. Иначе `irm | iex` не работает: Windows PowerShell 5.1 читает файл из GitHub Releases как Latin-1, и ни 5.1, ни 7 не пропускают BOM.
