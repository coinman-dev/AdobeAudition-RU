# Контекст проекта AdobeAudition-RU

Если в рабочей копии есть `.ai/PROJECT_CONTEXT.md`, прочитай его перед работой: это локальная рабочая память проекта (технические находки, как устроена локализация Audition). В репозиторий она не входит.

- Общайся с пользователем по-русски. Сообщения скрипта — на RU/EN через функцию `T 'рус' 'eng'`.
- `README.md` — на английском, `README.ru_RU.md` — на русском; одинаковая структура, переключатель языков вверху, полный список параметров.
- `Install-AuditionRU.ps1` — единственный файл установщика: UTF-8 с BOM и CRLF (иначе Windows PowerShell 5.1 ломает кириллицу), совместимость с PowerShell 5.1 и 7, должен работать через `irm | iex` (никаких безусловных `exit`).
- В релиз идёт не сам исходник, а его ASCII-копия из `tools\New-Release.ps1`: `irm` отдаёт `iex` текст в Latin-1 (5.1) или UTF-8 (7.4) вместе с BOM, и файл с BOM не разбирается. Поэтому в исходнике не-ASCII допустим только в комментариях (в копию не попадают) и в тексте строк; не внутри `$(...)` в строках и не в кавычках-ограничителях — сборка тогда откажет.
- Язык — только настоящий `ru_RU`; подмену другого языка (es_ES и т.п.) не делать.
- Ничего не удалять: заменяемые файлы переносить в `<Audition>\AdobeAudition-RU\backup`, всё записывать в `state.json`, `Restore` возвращает байт в байт.
- Словари (`*.dat`, `*.dict`, `learn-panel/**/*.txt`) — двоичные в Git; после любой правки: `tools\New-Release.ps1` (обновляет `manifest.json`) и `tests\Test-AuditionRU.ps1`.
- Тесты не меняют систему: полный цикл идёт на копии Audition в `tmp\`, реестр и сеть — заглушки. Реальную установку проверять только с согласия пользователя.
- Не более 3 параллельных агентов.
- Локальные каталоги `.ai/`, `tmp/`, `out/` в Git не хранятся.
